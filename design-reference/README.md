# Orbital Atelier V2 -- canonical interactive design

**Start here:** `CatchUp_AI_Orbital_Atelier.html`. Open directly in a modern browser; it works offline without CDNs, backend or API keys. Click all nine routes, switch the entire UI between dark and light, rotate/select 3D-projected nodes, compare recovery scenarios, approve a local sample plan, tick off sample tasks and take the quiz.

This is a **self-contained visual/interaction simulation**. Its 3D view uses mathematical perspective projection on Canvas 2D, not WebGL. The production app must implement this experience using actual React Three Fiber v9 with real authorized data, semantic accessible controls and progressively enhanced 3D. Agent calls, PDFs, citations, scores, approvals, metrics and persistence are simulated or local demo state only.
