# Volunteer testing protocol (3–5 people)

Use the deployed app and **synthetic data only** (the one-click demo, or the sample PDF in `data/`). Ask for verbal consent before each session; record no personal data beyond a first name or alias.

## Tasks (20 minutes)
1. Start the demo and say, in one sentence, what the briefing tells you.
2. Ask the copilot for help after a missed class; open one citation.
3. In the recovery lab, choose a route you could actually follow and approve it.
4. Find tomorrow's study blocks and mark one done.
5. Take a knowledge check; find where a wrong answer is explained in your notes.
6. Switch to dark mode and back.
